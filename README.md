# Page d'accès aux essais — Taxi DZ

Page envoyée aux testeurs : où installer les applications, avec quels comptes, et dans quel ordre
dérouler un tour complet.

## ⚠️ Ne pas éditer ici

La source est `apps/acces/index.html` dans le monorepo privé `ttokkee/taxi-dz`, publiée par
`scripts/publier-page-acces.sh`. Une modification faite directement ici serait écrasée à la
publication suivante.

## Pourquoi ce dépôt est public

GitHub Pages n'existe pas sur un dépôt privé sans plan payant, et cette page doit s'ouvrir sur le
téléphone d'un testeur, sans compte ni installation. Il ne contient aucun code produit : une page,
des liens, des consignes.

## Ce qu'elle expose, et ce que ça implique

La page porte les **identifiants de l'environnement d'essai**. C'est un choix assumé — elle doit
pouvoir s'envoyer en une fois, sans échange de codes en parallèle — mais quiconque trouve l'adresse
peut se connecter à cet environnement. Il ne contient que des données fictives et aucun argent n'y
circule.

**Le jour où ce ne sera plus vrai, cette page doit disparaître ou perdre ses codes.**
